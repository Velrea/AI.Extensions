# AI.Extensions

A Claude Code plugin marketplace from Velrea.

## Add the marketplace

```bash
claude plugin marketplace add Velrea/AI.Extensions
```

Then install a plugin by name:

```bash
claude plugin install <plugin>@ai-extensions
```

## Plugins

Each plugin lives in `plugins/<name>/` and carries its own README.
