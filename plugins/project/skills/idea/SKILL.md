An idea is something that might be worth doing, with no commitment. Each is one file in `docs/ideas/`, named for the idea.

## Capture

Before writing, look for an existing idea on the same thing and add to it instead.

Name the subject the idea concerns, then capture what the user said and what was discussed, at whatever length that takes. Invent nothing the conversation did not hold. No status, priority, or acceptance criteria.

## Triage

List the ideas as numbered one-liners. The user answers each with promote, drop, or keep. Promote hands the idea to `project:work`, which creates the item and keeps the idea until the work is done. Drop deletes the file, never marks it.
