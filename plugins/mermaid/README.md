# mermaid

Mermaid diagrams that read cleanly where they're published.

Mermaid lays a diagram out for you, and as it grows, lines start crossing each other, running through boxes, and the text shrinks until nobody can read it. You only find out once it's on the page. This plugin renders each diagram the way GitHub will show it, as an image you or Claude can look at and fix before it's committed.

- Renders with the same Mermaid release GitHub uses, or with Mermaid 12 and its new layout.
- Shows the error a reader would see when a diagram won't render.
- Nothing to install beyond Node and a Chromium-based browser: Edge, Chrome, or Chromium.

## Install

```bash
claude plugin install mermaid@ai-extensions
```
